# Abra sua Bíblia!

A website to read the Bible in the translation of your choice: https://www.abrasuabiblia.com.br

Built with TypeScript, [Svelte 5](https://svelte.dev) (without SvelteKit) and [Vite](https://vite.dev), deployed on
[Vercel](https://vercel.com).
