# Schema do EBF1

`ebf1-schema.json` é uma cópia do schema oficial do
[Easy Bible Format](https://github.com/natanael127/easy-bible-format)
(commit `2a9cb68`). Os testes em `tests/data/bibles.test.ts` validam todas as
Bíblias publicadas contra ele. Ao atualizar o formato, copie o arquivo novo
para cá.
